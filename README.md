# ZombieApocalypse

Paper용 좀비 아포칼립스 플러그인. 설계와 단계별 구현 범위는 [PLAN.md](PLAN.md), 현재 상태는 [인수인계](docs/HANDOFF.md)에 있다.

현재 버전 `0.2.0`은 PLAN의 확정 기능을 모두 구현했다. 단위 테스트와 실제 Paper 서버 콘솔 검증을 통과했고, 클라이언트로 직접 플레이하는 검증은 아직 하지 않았다([TESTING](docs/TESTING.md)).

## 기능 요약

- `/apocalypse start`를 하면 "좀비 아포칼립스" 타이틀과 3, 2, 1 카운트다운(기본 6초) 뒤에 그 월드에서 낮에도 타지 않는 좀비가 계속 몰려온다. 카운트다운 동안은 평소 마인크래프트와 같다. 자연 스폰, 스포너, 순찰대의 적대적 몹(크리퍼, 스켈레톤, 거미 등)만 커스텀 좀비로 바뀐다.
  - 돼지, 소, 여우 같은 동물과 주민, 골렘은 건드리지 않는다.
  - 엔더드래곤, 위더, 워든, 엘더 가디언, 스폰알, 습격도 그대로 둔다.
  - 시작 후 3분 동안은 햇빛(하늘빛)이 닿는 곳에는 좀비가 스폰되지 않는다. 나무 그늘과 다크 포레스트의 큰 버섯 아래도 포함하고, 동굴은 그대로다. 플레이어에게 따로 알리지 않는다. `/apoc status`에만 남은 시간이 보인다.
  - 시작하는 순간 그 월드에 이미 있던 몬스터(로드된 청크의 크리퍼, 스켈레톤, 일반 좀비 등)를 지운다. 동물, 주민, 골렘, 이름표를 붙인 몹, 엔더드래곤 같은 제외 몹은 남는다.
  - 한 지점 주변(48블록) 커스텀 좀비가 상한(기본 40, 날짜와 블러드문에 따라 증가)에 닿으면 자연 스폰과 추가 스폰을 멈춘다. 좀비 웨이브는 이 상한과 별개로 온다.
  - 낮에 햇빛이 닿는 곳(지상, 나무 그늘 포함)은 돌아다닐 수 있게 훨씬 적게 나온다. 상한은 4분의 1(기본 10)이고, 5초마다 플레이어 1명 주변에 최대 1마리만 추가된다. 동굴, 밤, 블러드문은 그대로 많이 나온다(`spawning.daylight`).
  - 좀비끼리는 서로 공격하지 않는다(근접, 투사체, 부머·봄버 폭발 모두).
- 좀비 타입 20종이 랜덤으로 나온다. 날짜가 지날수록 새 타입이 풀리고 체력과 공격력이 오른다.

  | 타입 | 특징 |
  | --- | --- |
  | 기본, 스프린터 | 기본 / 매우 빠름 |
  | 부머, 봄버 | 죽으면 1초 뒤 폭발 / 다가와서 자폭(퓨즈 중에 잡으면 안 터짐) |
  | 스로어, 맹독, 프로스트, 흡혈귀 | 맞으면 날아감 / 독과 허기 / 얼어붙음 / 때린 만큼 회복 |
  | 점퍼, 닌자, 그래버 | 높은 곳으로 뛰어듦 / 평소 투명 / 블리츠크랭크식 갈고리(피할 수 있음) |
  | 증식, 스크리머, 힐러 | 죽으면 분열(자식도 분열) / 워든 소리로 비명을 질러 주변을 어둡게 하고 좀비와 좀비 웨이브를 부름 / 주변 좀비 회복 |
  | 스피터, 필러 | 산성 웅덩이 / 목마 탑 |
  | 도둑, 네크로맨서, 자키 | 때릴 때마다 인벤토리 아이템 하나를 바닥에 쳐서 떨어뜨림(대미지 대신, 라디오·안테나 제외) / 땅에서 좀비를 일으킴 / 머리에 올라타 시야를 가림(웅크리기 3번으로 떨침) |
  | 위치 | 제자리에서 울다가 5블록 안에 오거나(웅크리면 2.5블록) 때리면 깨운 사람만 아주 빠르게 쫓아가 세게 때림. 그 사람이 쓰러지거나 30초가 지나면 다시 앉아서 움. 좀비 웨이브에는 안 나옴 |

- 보스 탱크: 블러드문마다, 10일차마다, 좀비 웨이브 마지막에 확률로, 구조 피날레 중에 나온다. 주먹, 바위 던지기, 지면 강타를 쓰고 불에 약하다. 처치 보상은 황금사과(다이아몬드 없음).
- 7일마다 블러드문, 3일마다 좀비 웨이브(경고 후 여러 차례 몰려옴). 스크리머 비명으로도 좀비 웨이브가 온다. 다 같이 잠들어 블러드문 밤을 넘기는 것도 가능하다.
- 네더와 엔드는 `/apoc start world_nether`처럼 따로 켠다. 이 월드들은 시계가 없어서 메인 오버월드의 시간과 날짜를 따른다.
- 죽은 플레이어 자리에 그 플레이어의 머리를 쓴 좀비가 생긴다. 아이템은 바닐라처럼 그 자리에 떨어진다.
- 좀비에게 죽으면 사망 메시지에 좀비 종류가 나온다(예: "Steve이(가) 부머 좀비에게 당했습니다."). 맞고 10초 안에 떨어지거나 폭발, 산성 웅덩이로 죽어도 그 좀비로 친다.
- 새 날이 되면 화면에 "N일차"만 뜬다. 게임 안 안내 문구는 모두 존댓말이다.
- 엔딩: 라디오와 안테나를 만들어 붙여 설치하고, 라디오를 두 번 우클릭하면 5분 구조 피날레가 시작된다. 버티면 약 100블록 떨어진 탈출 지점이 생기고, 3분 안에 도착하면 탈출 성공이다.
  - 조합법은 작업대 배치가 정해져 있다(사용자가 준 그림 그대로). 시작할 때 레시피북에 둘 다 추가된다.

    | 아이템 | 윗줄 | 가운데 줄 | 아랫줄 |
    | --- | --- | --- | --- |
    | 라디오 | 다이아몬드 블록, 레드스톤 블록, 다이아몬드 블록 | 레드스톤 블록, 바다의 심장, 레드스톤 블록 | 레드스톤 횃불, 소리 블록, 레드스톤 횃불 |
    | 안테나 | 빈칸, 철 사슬, 빈칸 | 블레이즈 막대기, 레드스톤 가루, 블레이즈 막대기 | 빈칸, 철 사슬, 빈칸 |

  - 조합해도 바로 나오지 않는다. 재료가 들어가고 그 작업대에서 조립이 시작된다(라디오 1분 30초, 안테나 45초). 조립하는 동안 좀비 웨이브가 계속 오고, 작업대 8블록 안에 생존자가 없으면 조립이 멈춘다. 끝나면 조합한 사람에게 아이템을 준다. 조립 중인 작업대는 부술 수 없고 폭발에도 남는다. 크래프터(자동 제작기)로는 만들 수 없다.
  - 안테나(엔드 막대기)는 라디오 바로 위나 옆(동서남북)에 붙여 설치해야 한다. 안테나가 없으면 구조를 요청할 수 없다. 안테나도 폭발에 부서지지 않고, 웅크려 부수면 회수된다.
  - 라디오는 하늘이 보이는 지면 높이의 단단한 땅 위에만 설치할 수 있다. 공중, 얇은 발판, 지붕 아래, 동굴에는 놓을 수 없다.
  - 피날레 동안 라디오와 높이 차이가 8블록 넘게 나는 곳에 있으면 지키는 것으로 치지 않는다.
  - 탈출 지점(구조 헬기)에는 벽 너머로도 보이는 노란 발광 헬기장, 빛기둥, 이름표가 생긴다.
  - 안테나 재료인 블레이즈 막대기를 얻을 수 있게, 스포너(네더 요새)에서 나오는 블레이즈는 좀비로 바꾸지 않는다. 자연 스폰 블레이즈는 그대로 좀비가 된다.
  - 엔딩이 끝나면 3초 뒤 채팅에 생존 기록이 나온다. 버틴 날짜, 플레이어별 처치·사망 수와 가장 많이 잡은 좀비, 탈출/낙오, 최다 처치·최다 사망·탱크 처치·도둑에게 가장 많이 털린 사람. 기록은 data.yml에 저장되어 재시작해도 이어진다.

## 게임 진행 명령어

권한 `zombieapoc.admin`(기본 op). 게임 안에서는 `/apocalypse` 또는 `/apoc`, 콘솔에서는 앞의 `/`를 뺀다.

| 명령어 | 내용 |
| --- | --- |
| `/apoc start [월드] [초\|now]` | 타이틀과 3, 2, 1 뒤 시작(기본 6초, `now`는 바로). 10초보다 길게 주면 남은 시간 보스바도 뜬다. 시작되면 그 월드의 기존 몬스터가 사라지고, 라디오와 안테나 조합법이 레시피북에 추가된다 |
| `/apoc stop [월드]` | 종료(준비 중이면 취소). 커스텀 좀비를 모두 정리한다 |
| `/apoc status` | 준비 남은 시간 또는 날짜, 블러드문, 좀비 웨이브, 타입별 좀비 수, 조립과 엔딩 진행 |
| `/apoc stats [월드]` | 지금까지의 생존 기록(엔딩 때 나오는 것과 같은 표). 명령어를 쓴 사람에게만 보인다 |
| `/apoc reload` | `config.yml` 다시 읽기. 문법 오류면 이전 설정 유지 |
| `/apoc set [설정] [값]` | 플레이 중 실시간 조정. 값을 확인해 바로 적용하고 `config.yml`에 저장한다(첫 변경 때 원본은 `config.yml.bak`). 잘못된 값이면 바꾸지 않는다. 인자 없이 쓰면 주요 스폰 설정과 현재 값이 나오고, 줄을 클릭하면 입력창에 명령이 들어간다. 설정 이름은 탭으로 한 단계씩 완성된다. 예: `/apoc set spawning.extra.per-player-cap 60` |
| `/apoc spawn <타입> [수]` | 바라보는 곳에 소환. 콘솔은 `spawn <타입> <수> <월드> <x> <y> <z>` |
| `/apoc egg <타입\|all> [수] [플레이어]` | 테스트용 스폰알 지급. 우클릭한 곳에 그 타입 좀비가 나온다(아포칼립스가 켜진 월드에서만). `all`은 21종을 한 번에 |
| `/apoc day [set <n>]` | 날짜 확인/변경 |
| `/apoc bloodmoon <start\|stop>` | 블러드문 강제 시작/종료 |
| `/apoc wave <start\|stop>` | 좀비 웨이브 바로 시작/종료 (`horde`도 같은 명령) |
| `/apoc radio <give [플레이어]\|status\|reset>` | 라디오와 안테나 지급(조립 없이 바로) / 엔딩 상태(라디오, 안테나, 조립) / 엔딩 초기화 |
| `/apoc finale <start\|skip>` | 피날레 바로 시작 / 건너뛰고 탈출 단계로 |
| `/apoc escape skip` | 탈출 단계를 끝내고 엔딩으로 |

모든 수치는 `server/plugins/ZombieApocalypse/config.yml`에서 바꾼다. 항목 설명은 [config.yml](src/main/resources/config.yml)에 있다.

## 준비된 서버 실행

1. 이 PC의 서버는 사용자 동의에 따라 `eula=true`로 설정되어 있다. 새로 설치하는 경우에는 Minecraft [EULA](https://aka.ms/MinecraftEULA)를 확인하고 동의하는 경우에만 `server/eula.txt`를 변경한다.
2. 프로젝트 폴더의 `start-server.bat`를 더블클릭한다. 첫 실행은 인터넷 연결이 필요하며 서버 라이브러리와 월드를 준비한다.
3. 콘솔에 `Done`이 나온 뒤 **Minecraft Java Edition 26.2**에서 실행 스크립트가 표시한 주소로 접속한다. 이 PC의 주소는 `localhost:25565`다. 포트는 `server/server.properties`의 `server-port`를 따른다.
4. 서버 콘솔에서 `op 본인닉네임`을 실행한 뒤 게임 안에서 `/apoc start`로 시작한다. 콘솔에서는 `apocalypse start world`로 실행한다.
5. 서버 종료는 콘솔에 `stop`을 입력한다.

2026-10-25 실제 서버에서 0.1.0 로드와 정상 종료를 확인했고, 같은 날 0.2.0의 콘솔 기능 검증을 임시 월드에서 마쳤다([BUILD_REPORT](docs/BUILD_REPORT.md)). 이후 클라이언트 입장과 `/apoc start`, 스폰알 사용도 서버 로그로 확인했다(당시 포트 25599, 지금은 25565로 되돌림). 전체 플레이와 LAN/외부 접속은 별도 확인이 필요하다.

| 항목 | 설정 |
| --- | --- |
| Paper | 26.2 빌드 129 (STABLE, 플러그인 API 버전과 일치) |
| Java | 25, 이 PC에서는 `C:\Program Files\Java\jdk-25.0.2` |
| 플러그인 | `server/plugins/ZombieApocalypse-0.2.0.jar` |
| 메모리 | 최소 1GB, 최대 4GB |
| 게임 | 서바이벌, 어려움, 최대 10명 |
| 전투 | PvP 끔. 아포칼립스가 켜진 월드는 플러그인이 몬스터 스폰 상한과 주기를 바꾸고, 끄면 되돌린다 |
| 거리 | 시야 8청크, 시뮬레이션 6청크 |
| 접속 | 포트 25565 (`server.properties` 기준), 정품 인증 켬 |
| 기타 | 스폰 보호 0, 능력 이동 대비 `allow-flight=true` (비행 능력을 주는 설정은 아님) |

같은 공유기의 다른 PC에서는 서버 PC의 사설 IP와 설정된 포트(`:25565`)로 접속한다. Windows 방화벽 허용과 외부 접속용 공유기 포트포워딩은 별도이며 이번 준비 과정에서 변경하지 않았다. 화이트리스트는 기본적으로 꺼져 있으므로 외부에 개방할 때에는 콘솔에서 `whitelist on`, `whitelist add 닉네임`으로 참가자를 제한할 수 있다.

메모리를 조정하려면 PowerShell에서 다음처럼 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-server.ps1 -MinMemory 1G -MaxMemory 6G
```

## 빌드 및 서버에 반영

이 PC에서는 사용자가 서버를 직접 켜고 플러그인 JAR도 직접 넣는다.

1. 서버 콘솔에 `stop`을 입력해 서버를 끈다.
2. `build/libs/ZombieApocalypse-0.2.0.jar`를 `server/plugins`에 덮어쓴다(같은 파일 이름).
3. 서버를 다시 켠다.

PowerShell 스크립트로 빌드와 복사를 한 번에 하려면 서버를 `stop`으로 종료한 뒤 실행한다.

```powershell
# 빌드 + 테스트 + 서버 플러그인 갱신. Paper가 이미 설치된 현재 PC에서 사용.
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-server.ps1 -Offline

# 새 PC에서 Paper까지 내려받아 준비하는 경우
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-server.ps1
```

`setup-server.ps1`은 고정한 Paper JAR의 SHA-256을 검증하고 플러그인을 복사한다. 기존 서버 설정, EULA 값과 월드는 보존한다. 다른 버전의 ZombieApocalypse JAR가 있으면 중복 로드를 막기 위해 중단하므로, 버전을 올릴 때는 이전 JAR를 `server/plugins`에서 먼저 뺀다(0.1.0 → 0.2.0은 이 PC에서 처리해 두었다). 서버 파일과 월드는 `server/` 아래에 있으며 Git에서 제외된다.

공식 자료: [Paper 시작 안내](https://docs.papermc.io/paper/getting-started/), [Paper 다운로드 API](https://docs.papermc.io/misc/downloads-service/).

검증 범위는 [TESTING](docs/TESTING.md)과 [BUILD_REPORT](docs/BUILD_REPORT.md)에 기록한다.
