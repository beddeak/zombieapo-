# 검증 절차

## 자동 검증

프로젝트 루트에서 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Offline
```

JUnit 보고서는 `build/reports/tests/test/index.html`, JAR는 `build/libs/ZombieApocalypse-0.2.0.jar`에 생성된다. 테스트 9개 클래스 66개가 다음을 확인한다.

서버를 종료한 뒤 `setup-server.ps1 -Offline`을 실행하면 같은 빌드 검증을 거쳐 서버 플러그인도 갱신한다. `-SkipBuild -Offline`은 이미 빌드된 JAR만 배치한다.

## 서버 콘솔 검증 (플레이어 없이)

2026-10-25에 실행한 방법과 결과는 [BUILD_REPORT](BUILD_REPORT.md)에 있다. 다시 하려면 다음 순서를 따른다.

1. `start-server.bat`로 서버를 켜고 `Done`과 `Enabling ZombieApocalypse v0.2.0`을 확인한다.
2. 콘솔: `forceload add -16 -16 15 15`, 그다음 `summon`으로 크리퍼, 스켈레톤, 소, 주민, 철 골렘, 이름 붙인 크리퍼(`{CustomName:"Named"}`)를 둔다. `apocalypse start world now` → 로그 `Removed N vanilla monsters at the start`, `execute if entity @e[type=...]`로 이름 없는 몬스터만 사라졌는지 본다. 이어서 `time set 6000`
3. 콘솔: `apocalypse spawn <타입> 1 world <x> <y> <z>`로 각 타입을 소환하고 `apocalypse status`로 타입별 수를 본다.
4. 40초 이상 지난 뒤 `apocalypse status`의 수가 그대로인지, `data get entity @e[type=minecraft:zombie,limit=1,sort=nearest,x=<x>,y=<y>,z=<z>] Fire`가 `0s`인지 본다(햇빛 면역).
5. `apocalypse day set 7`, `time set 13000` → 블러드문 시작 메시지. `apocalypse bloodmoon stop`/`start`도 확인한다.
6. `kill @e[type=#minecraft:zombies,...]` → 부머 폭발, 증식 분열, 탱크 보상 메시지를 확인한다.
7. 크래프터: 크래프터 3개에 철 주괴 9개(대조군), 안테나 재료, 라디오 재료를 그림 배치대로 넣고(`setblock ... minecraft:crafter[orientation=north_up]{Items:[...]}`) 위에 레드스톤 블록을 놓는다. `data get block <x> <y> <z> Items`로 철 주괴만 조합되어 비고, 안테나와 라디오 재료는 그대로 남았는지 본다.
8. `apocalypse stop world` → 정리한 좀비 수 메시지, `apocalypse status` → 진행 중인 월드 없음.
9. `forceload remove all`, `stop`. 서버 로그에 `ZombieApocalypse` 관련 오류가 없어야 한다.

## 클라이언트 플레이 체크리스트

Java Edition 26.2로 `localhost:25565`에 접속하고 `op 닉네임`을 준 뒤 확인한다. 주소는 `server/server.properties`의 `server-port`와 실행 스크립트의 안내를 따른다. 실행하지 않은 항목은 통과로 기록하지 않는다.

2026-10-25 서버 로그에서 로컬 클라이언트 입장과 `/apoc start` 성공까지 확인했다. 아래 시각 효과와 능력별 체크리스트는 아직 완료하지 않았다.

**시작과 스폰**
- [ ] `/apoc start` → "좀비 아포칼립스" 타이틀, 이어서 3, 2, 1 숫자, 그다음 "1일차". 그동안 좀비 아포칼립스 효과 없음. `/apoc start 60`은 보스바와 함께 1분 뒤 시작
- [ ] 준비가 끝나면 레시피북에 라디오와 안테나 조합법, 화면에 "1일차"만(아래 문구 없음). 안내 문구가 존댓말인지
- [ ] 시작 전에 있던 크리퍼, 스켈레톤 등은 시작하는 순간 사라지고 동물, 주민, 철 골렘, 이름표 몹은 남는다
- [ ] `/apoc start now`는 바로 시작, 준비 중 `/apoc stop`은 시작 취소
- [ ] 낮에 주변 20~40블록에 좀비가 계속 나타나고 타지 않는다
- [ ] 밤에 크리퍼/스켈레톤/거미가 나오지 않고 좀비로 바뀐다. 사막은 허스크, 물속은 드라운드
- [ ] 돼지, 소, 여우, 양, 닭, 주민은 그대로 남는다
- [ ] 1~2분 지나도 `/apoc status`의 커스텀 좀비 수가 수백 마리로 늘지 않는다(한 지점 주변 상한 기본 40)
- [ ] 좀비끼리 서로 때리거나 노리지 않는다. 드라운드 삼지창, 부머 폭발에도 다른 좀비는 다치지 않는다
- [ ] 좀비 피글린이 먼저 공격한다
- [ ] OP가 아닌 플레이어는 `/apoc` 명령을 쓸 수 없다

**타입별** (`/apoc egg all`로 스폰알 20종을 받아 우클릭으로 소환하거나 `/apoc spawn <타입>`으로 확인)
- [ ] 스프린터 빠름 / 부머 사망 1초 뒤 폭발 / 봄버 접근 후 깜빡이다 폭발, 퓨즈 중 처치 시 안 터짐
- [ ] 스로어 날리기 / 맹독 독·허기 / 프로스트 얼어붙음 / 흡혈귀 회복 파티클
- [ ] 점퍼가 높은 곳으로 뛰어오름, 낙하 피해 없음 / 닌자 투명, 4블록 안에서 드러남
- [ ] 그래버 예고 후 직선 갈고리, 옆으로 피하면 빗나감, 블록 뒤에 숨으면 막힘, 맞으면 끌려옴
- [ ] 증식 분열과 자식 재분열, 세대가 내려갈수록 작아짐 / 스크리머: 스컬크 비명과 워든 포효, 주변 플레이어 화면 어둠과 심장 소리, 주변 좀비가 몰려옴 / 힐러 하트 파티클
- [ ] 스피터 산성 웅덩이 / 필러 탑, 실내에서는 탑을 만들지 않음
- [ ] 도둑이 때릴 때마다(처음 한 번) 반드시 아이템을 훔치고 도망(무기만 있으면 무기도), 라디오·안테나는 안 훔침, 잡으면 아이템 드롭(내구도 그대로), 골렘·낙사 등 플레이어가 아닌 원인으로 죽어도 드롭, 용암에서 죽으면 주인에게 반환. 토템을 훔친 도둑은 부활하지 않고 토템이 떨어짐
- [ ] 네크로맨서가 좀비를 땅에서 일으키고, 네크로맨서가 죽으면 같이 쓰러짐
- [ ] 자키가 머리에 올라타 실명, 웅크리기 3번 또는 다른 플레이어 타격으로 떨어짐, 6초 후 자동 해제, 실명 해제

**이벤트**
- [ ] 3일차에 좀비 웨이브: 뿔피리 방향, 보스바, 여러 차례 몰려옴, 다 잡으면 "좀비 웨이브를 막아냈습니다"
